# 무릎 부담 최소화 하체 루틴 (어썸블리스) — 참고 자료

**출처**: [논문이 말하는 무릎에 좋은 헬스장 하체 운동 루틴 (순서가 중요!)](https://www.youtube.com/watch?v=h0NmtiByMEo) — 어썸블리스 AwesomeBLISS, 2026-08-14 시청
**용도**: 나중에 FORGE40 하체 프로그램(하체 A/B) 조정 시 참고할 무릎 친화 루틴. **아직 프로그램에 반영하지 않음** — 반영 결정은 별도로.

> **근거 수준 주의**: 이 문서는 영상 설명란(운동 순서·원리·챕터)과 루틴 요약 화면 캡처를 기반으로 정리했고, 자막 전문은 확인하지 못했습니다. 종목별 세부 자세·가동범위 설정법은 아래 타임스탬프에서 영상을 직접 확인하세요. 의학적 조언이 아닙니다.

## 1. 핵심 메시지

- **무릎이 아프다고 하체 운동을 계속 피하면, 약해진 하체 때문에 무릎은 점점 더 불안해진다** — 쉬는 것만이 회복이 아님 (영상 표현: "안티프래질").
- 통증을 억지로 참으라는 뜻이 아니라, **지금 통증 없이 할 수 있는 범위 안에서** 발목 → 고관절 → 무릎 주변 근육을 차근차근 강화해 "앉고 일어나는 움직임"을 회복하는 것.
- 단순 종목 나열이 아니라 **순서 · 자세 · 가동범위 설정**이 핵심.

## 2. 순서의 논리 (영상 설명란 그대로)

1. **종아리·전경골근** — 발목을 먼저 준비 (하체 혈류·관절 워밍업)
2. **내전근(이너타이)·엉덩이(아웃타이)** — 고관절 균형 회복, 무릎 정렬 안정
3. **햄스트링(레그컬)** — 무릎의 안정성 담당 후면 강화
4. **허벅지 앞쪽(레그익스텐션)** — 통증 없는 범위로 단계적 강화
5. **레그프레스** — 무릎 부담이 상대적으로 적은 복합 압축 운동
6. **핵스쿼트** — 쪼그려 앉기(스쿼트 패턴) 연습, 무릎 부담 없는 방법으로

## 4. FORGE40 현재 프로그램과의 매핑

| 영상 종목 | FORGE40 현황 | 비고 |
|---|---|---|
| 아웃타이 | ✅ 어브덕터 — 하체B에 이미 있음 | 그대로 대응 |
| 이너타이 | ❌ 없음 | TechnoGym 어덕터 머신 유무 확인 필요 |
| 레그컬 | ⚠️ 프로그램에서 스미스 RDL로 대체했었음 | 영상은 무릎 안정성 목적의 저부하 포함을 권함 |
| 레그 익스텐션 | ⚠️ 데드리프트로 대체했었음 (무릎 배려) | 영상은 "통증 없는 범위 설정"으로 오히려 포함하는 접근 |
| 레그프레스 | ⚠️ 스미스 스쿼트·고블릿으로 대체했었음. 과거 로그: 레그 프레스에서 무릎 문제 보고 이력 있음 | 본인 경험이 일반론보다 우선 (프로토콜 §3) — 재도입 시 신중 |
| 핵스쿼트 | ❌ 없음 | 헬스장 기구 유무 확인 필요. 유사 대체: 스미스 머신 스쿼트 |
| 종아리·전경골근 | 카프 레이즈 있음 / 전경골근(토 레이즈)은 없음 | 웜업으로 넣기 좋음 |

**FORGE40와의 관점 차이** (반영 판단 시 핵심 쟁점): FORGE40는 무릎 부담 종목을 **회피·대체**하는 쪽이었고, 이 영상은 **통증 없는 범위에서 저부하로 포함해 다시 강화**하는 쪽. ACSM 원칙(30~100%1RM 어디서든 효과 동일 → 저부하·고반복 선택은 손해가 아님)과는 양쪽 다 부합한다. 단, 사용자 본인의 실제 로그(레그 프레스 무릎 불편 이력)가 일반론보다 우선한다는 프로토콜 규칙은 유지.

## 5. 활용 아이디어 (반영 시 검토할 것)

1. **웜업 통합** — 하체 A/B 웜업에 "발목 준비(종아리·전경골근) → 아웃타이/이너타이 가볍게" 순서를 추가 (기존 무릎 5원칙 웜업과 병합).
2. **무릎 컨디션 나쁜 날의 대체 세션** — 체크인에서 무릎 통증 mild가 보고된 날, COACHING-PROTOCOL §3.1 무릎 행의 대체안으로 이 루틴(저부하 8~12회×2세트)을 제시.
3. **정식 반영 시** — SESSIONS에 세션(예: `kneeCare`)으로 추가하고, 부위별 주 10세트↑·주 2회↑ 유지 여부 확인 (ACSM §6 규칙 7). 이너타이·핵스쿼트는 기구 확인 후.
4. 어느 쪽이든 **반영 결정은 CHANGELOG에 기록**하고, 레그프레스 계열은 본인 무릎 반응을 1~2회 저부하로 테스트한 뒤 판단.
